# Waste Management & Recycling Analytics

## 📌 Project Overview

This project analyzes waste generation, recycling rates, disposal methods, management costs, and waste-management performance across cities in India.

The goal is to identify important patterns and business insights that can support better waste-management decisions.

## 🛠️ Tools & Technologies

- Excel – Data cleaning and preparation
- Python – Exploratory Data Analysis (EDA)
- SQL – Business analysis and data querying
- Power BI – Interactive dashboard and visualization

## 📊 Key Analysis

- Total and average waste generated
- Waste generation by waste type
- Recycling rate by waste type
- Waste trends by year
- Waste generated by disposal method
- Top cities by waste generation
- Top cities by recycling rate
- Waste-management cost analysis
- Population density vs waste generation

## 🔍 Key Insights

- Plastic generated the highest total waste.
- Jaipur had the highest total waste generation among the cities.
- Indore had the highest average recycling rate.
- Incineration handled the highest total amount of waste.
- Construction had the highest average management cost among waste types.
- The relationship between population density and waste generation was very weak in this dataset.

## 📈 Power BI Dashboard

The dashboard provides interactive analysis using Year, Waste Type, and Disposal Method filters.

## 🎯 Project Outcome

The project demonstrates how Excel, Python, SQL, and Power BI can be used together to transform data into meaningful business insights and support data-driven decision-making.
